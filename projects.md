## API Demos

These are live, interactive widgets that pull real data from public APIs. Each one is paired with or connected to documentation in the [Writing Samples](/writing-samples/) section.

### PokeAPI Widget

A search tool that pulls data from [PokeAPI](https://pokeapi.co/) — a free, public API for Pokémon data. Type in a Pokémon name and it returns the type, abilities, and a sprite image in real time.

**What it demonstrates:** Making a GET request to a public API, parsing a JSON response, and rendering data dynamically in the browser.

**Related writing:** [PokeAPI User Guide](/writing-samples/pokeapi/) — a beginner-friendly walkthrough of how the widget works and what's happening behind the scenes.

[View the PokeAPI demo](api-demos/pokeapi-widget.html)

### Gutendex Widget

A search tool that pulls book data from [Gutendex](https://gutendex.com/) — a web API for Project Gutenberg's catalog of public domain books. Search by title and it returns the book's authors, languages, and a link to read it online.

**What it demonstrates:** Querying a text-based API, handling search results, and linking out to external resources.

[View the Gutendex demo](api-demos/gutendex-widget.html)
