This page collects writing samples organized by type. Each piece is something I've written or refined — some are polished guides, others are works in progress that I'm refining as I learn.

---

## User Guides

These are step-by-step guides written for non-technical audiences. The goal is clarity first: someone should be able to follow along without prior knowledge.

**[Clearing Cookies and Cache in Chrome](/writing-samples/clear-cookies-and-cache-in-chrome/)** — A focused guide to clearing cookies in Chrome, including what happens afterward and why it matters. Written in plain language with tips for common follow-up questions.

**[Clearing Cookies: General Browser Guide](/writing-samples/clearing-cookies-user-guide/)** — A browser-agnostic version of the same topic, written as a quick-reference guide. This one is a bit rougher — it's an earlier draft I'm keeping as a comparison point while I continue to refine my style.

## API Documentation

These samples demonstrate how to document APIs for non-developer audiences. Each one pairs a live, interactive widget with a written explanation of what's happening under the hood.

**[PokeAPI User Guide](/writing-samples/pokeapi/)** — A beginner-friendly walkthrough of how to use PokeAPI, paired with a live search demo. Covers GET requests, JSON responses, and how to read real API data — no coding experience needed.
